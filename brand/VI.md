# Grove 视觉识别（VI）

Grove 的品牌主张：**积累可回看、可修正的知识，形成自己的判断。** 视觉上要克制、具体、可核对——像一份归档良好的笔记，而不是一张宣传海报。

## 1. 标志

- **构成**：两片叶（大的深绿、小的浅绿）+ 一条向上收窄的茎 + 一条琥珀色基线。
- **含义**：叶是观点与证据，茎是它们共同的来源，琥珀色基线是"落盘"这一动作——Grove 只在人确认后才留下东西。
- **三个版本**：
  | 文件 | 用途 |
  | --- | --- |
  | `brand/mark.svg` | 浅底（Paper、白） |
  | `brand/mark-on-dark.svg` | 深底（Ink） |
  | `brand/mark-mono.svg` | 单色印刷、水印、需要单一油墨的场合 |
- **最小尺寸**：图形 ≥ 24 px；插件行图标 36 px；再小只用 `icon.svg` 的 16 px 场景，且不再加任何细节。
- **清晰空间**：四周至少留出标志高度的 1/4，不与文字或边框贴边。
- **禁止**：旋转、拉伸、改比例；换用调色板以外的颜色；加描边、投影、发光、渐变；拆开叶子单独使用；放在与叶片同明度的背景上。

## 2. 锁定组合

| 文件 | 场景 | 最小宽度 |
| --- | --- | --- |
| `brand/logo-light.svg` | 浅底 | 120 px |
| `brand/logo-dark.svg` | 深底或图片上 | 120 px |
| `brand/logo-zh.svg` | 需要中英并置时 | 140 px |

字标固定用下方拉丁字体、600 字重、字距 -0.5（在 26 px 字号下）。字标与标志的间距固定为标志高度的约 1/4，不随手改。

## 3. 色彩

| 名称 | Hex | 纸白上的对比度 | 用途 |
| --- | --- | --- | --- |
| Ink | `#1B3A2E` | 11.3:1 | 正文、标题、深色底 |
| Ink soft | `#40514A` | 7.7:1 | 次级正文 |
| Ink muted | `#5A6B61` | 5.2:1 | 说明、元信息、等宽标签 |
| Green | `#2F7D5B` | 4.5:1 | 强调、链接、图形主色 |
| Leaf | `#5FA37E` | 4.2:1（深底上） | 图形层次、深底上的第二片叶 |
| Green pale | `#8FC7A9` | 6.5:1（深底上） | 深底上的浅叶 |
| Amber | `#C98A3B` | 2.7:1 | **只做装饰**，不承载信息 |
| Amber strong | `#B87A2C` | 3.3:1 | 需要被辨认的琥珀色图形 |
| Amber text | `#8F5F1D` | 5.0:1 | 需要当作文字使用的琥珀色 |
| Paper | `#F7F4EC` | — | 浅色底 |
| Line | `#C3D3C9` | — | 分隔线、描边、标签边框 |

规则：正文只用 Ink / Ink soft / Ink muted；Green 不做小号正文；Amber 不做文字，除非换成 `Amber text`。

## 4. 字体

- 拉丁：`SF Pro Display`（标题）/ `SF Pro Text`（正文），回退 `Helvetica Neue, Helvetica, Arial, sans-serif`。
- 中文：`PingFang SC`，回退 `Source Han Sans SC, Noto Sans CJK SC, sans-serif`。
- 等宽：`SF Mono`，回退 `SFMono-Regular, Menlo, monospace`；用于资产 ID、版本号、标签，字距 2 px，全大写可选。
- 字重：标题 600，正文 400，强调不加粗而是换色。
- 字号阶梯：12 / 14 / 16 / 20 / 24 / 32 / 48 / 104 px。

## 5. 版式

- 间距一律 4 的倍数：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。
- 圆角：控件 6 px，卡片 10–12 px，标签 999 px（胶囊）。
- 底与边框：浅色卡片用 `#FFFFFF` 配 `Line`，深色块用 Ink，不加投影。
- 图文比例：一张版面最多一个焦点图形；文字块与图形之间留白大于文字行距。

## 6. 文案语气

- 短句，动词开头，说清楚边界；不承诺做不到的事。
- 例：`保存由你确认` / `证据回到出处` / `没有数据库，复制目录即备份`。
- 避免"颠覆""革命""最强"这类词；产品价值通过可核对的行为表达。

## 7. 资产与再生成

清单见 [`brand/README.md`](README.md)。所有 PNG 由 `brand/src/build.sh` 用本机 Chrome 渲染，改动 SVG 或 HTML 后重跑一次即可；`brand/` 不进入 npm 包，插件行只读根目录的 `icon.svg`。
