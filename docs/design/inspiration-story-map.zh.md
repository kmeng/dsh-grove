# 知林用户故事地图 · 从灵感到研究

| 用户活动 | 用户故事 | 原型中的验收 |
| --- | --- | --- |
| 随手记 | 我想在点子消失前记一句，然后继续手上的事。 | 输入原文，点「💡叮～」即完成。新记录出现在首页，带灯泡和记录时间。 |
| 找回来 | 我想扫一眼最近的想法，或凭记得的词找到以前的记录。 | 最近灵感和搜索结果使用同一种列表。点击进入「从灵感出发」，返回后保留搜索词。 |
| 看见联系 | 我想知道过去的哪些观察能帮我理解这条灵感，以及它们有什么关系。 | AI 自动提出相关灵感，并逐条说明理由。可打开相关原文。没有合适的关联时，详情仍可读。 |
| 决定要不要深挖 | 我可能只想留个想法。等我看见值得弄清楚的问题，再发起研究。 | 阅读后可以直接返回。选择「从这里深挖」可选取原文片段或采用 AI 提出的问题，确认后才创建研究。 |
| 独立发起 | 我已经有一个问题，想直接研究。 | 首页可点「独立发起研究」，只填问题即可请 AI 开始，也可以自己研究。 |
| 接续和回看 | 我想找回从这条灵感出发的研究，并打开已经留下的成果。 | 「从灵感出发」直接列出研究话题和最近进展，每份已有报告展示标题与正文摘要。报告、知识和作品都可打开，再沿来源回看。刚记录的灵感可以一直只有原文。 |
| 带着成果再探索 | 我想把一次研究变成可复用的理解，再用实践更新它。 | 报告可沉淀为知识或写成作品。知识可补实践反思，并发起下一轮研究。 |

AI 的关联是供阅读和提问的线索。研究来源在用户发起研究时确定，记录实际采用的灵感片段及版本。一个想法可以长出几个课题，一个课题也可以参考多条灵感。报告、知识和作品沿实际来源回到相应课题。

原型用街道步行的示例演示三种状态：只记录，出现 AI 关联，以及已有研究和成果。关联理由和研究回答使用示例数据。
