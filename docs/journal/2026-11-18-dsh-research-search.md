## 判断依据

- 在 DeepSeek Harness Desktop 0.2.2-rc.3 的隔离 profile 中，使用宿主 DeepSeek 模型及联网检索，Tavily 未开启。仅输入一句询问最近两天人民币对美元中间价的问题，无链接和附件。计划按北京时间展开为 11 月 17 日和 18 日，同一轮通过宿主检索取得资料并生成待确认草稿。
- 草稿内显示 8 个可点击的来源链接。核对中国货币网来源地址能访问，HTTP 返回 200。该验收确认了检索和引用路径，未把模型草稿页作为独立数据发布。
- 68 项测试通过。包清单含 39 项，dsh 兼容和临时 profile 安装通过。
- 正式包复验：从 npm 官方下载 `dsh-grove-0.6.3.tgz`，核对 registry 的 SHA-512，在隔离 profile 安装并确认版本为 0.6.3。用新建临时 vault 启动桌面；设置接口显示宿主检索可用、Tavily 关闭。只提交一句需要北京时间最近两天人民币对美元中间价的问题，未附链接和文件。运行记录确认走 dsh 宿主检索并获得 16 条公开材料。
- 首次运行在补查后的模型核验阶段超时。仅在隔离 profile 将原 DeepSeek Flash 模型的推理档位从 high 改为 low，桌面点击「重试」恢复同一轮，无需重新输入、上传或补链。随后生成覆盖 11 月 17 日和 18 日的待确认草稿。
- 草稿的「来源链接」列出 8 个可点击地址。逐个发起 HTTPS GET，6 个返回 HTTP 200，包括中国货币网和中国人民银行网站；搜狐及网易各有一条返回 HTTP 403。这一结果验证了点击入口与来源的可访问性边界。
