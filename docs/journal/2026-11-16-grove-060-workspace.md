## 判断依据

- 发布前，在 DeepSeek Harness Desktop 0.2.2-rc.3 的隔离 profile 和临时 vault 中，从首页用一句话找回「智能体 UX 设计线索」。打开灵感详情，点「由此发起研究」，从带着原灵感引用的对话发送第一个问题。第一轮完成后，在同一课题追问用户只有几秒决定是否接管时应该看到什么。两轮真实研究完成，保存记录指向同一个课题。
- 在桌面端确认报告草稿后，报告卡片显示「已确认」。点一次「提炼为知识」直接保存，无需填写标题或类型。打开知识笔记可直接阅读，再点「查看依据」能回查保存时关联的原报告版本。
- 从 npm 官方 registry 下载 `dsh-grove-0.6.0.tgz`，按 registry 元数据核对 SHA-512，在隔离 profile 安装并确认 manifest 版本为 `0.6.0`，宿主配置包含 Grove。用正式包启动桌面版，实测「叮」记录、用一句话找回，以及灵感详情的研究入口。
- 正式包打开已有测试课题时，在同一对话中显示两轮研究，两份已确认报告均可打开。实测从报告一键保存至知识库、打开知识正文并回查来源。设置页可见笔记库、默认模型、联网检索、文档解析和模型连接测试。
- 发布检查通过 63 项测试。打包清单含 38 个文件，宿主兼容性和隔离安装通过。
- 完整正式包复验：在同一隔离桌面 profile 中，以「叮」新记一条关于智能体产品文档示例域名的灵感。打开这条灵感，点「由此发起研究」，以 IANA 公开资料研究示例域名的使用范围；第一轮完成后，在原对话问误复制到生产环境该怎么处理。两轮均完成并在同一课题显示；落盘记录确认课题 ID 相同，课题引用新灵感的准确版本。
- 打开第二轮报告，确认草稿为第 2 版。点一次「提炼为知识」，生成一篇知识笔记。从该笔记点「查看依据」并打开「研究报告」，桌面显示原报告第 2 版及正文。落盘记录确认知识笔记指向第二轮报告的已确认第 2 版。
